# Soccer Stars Trajectory PRO

Android Java project for a screen-overlay trajectory predictor prototype.

## Build

The included GitHub Actions workflow builds a debug APK with Java 17, Android SDK 35 and Gradle 8.9.

No Android Studio is required for the GitHub Actions build.

## Important

The physics and computer-vision detector are approximations based on observable game visuals; they are not Miniclip's private game physics.
