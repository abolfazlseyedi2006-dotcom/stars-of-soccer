# ساخت APK با GitHub Actions

1. محتوای همین پوشه را مستقیماً داخل ریشه Repository آپلود کن؛ خود پوشه پروژه را به‌صورت یک پوشه تو در تو آپلود نکن.
2. بعد از Push، از تب **Actions** ورک‌فلو **Build Soccer Stars APK** را باز کن.
3. اگر خودکار اجرا نشد، **Run workflow** را بزن.
4. وقتی سبز شد، وارد همان Run شو و از بخش **Artifacts** فایل `SoccerStarsTrajectory-V6-debug` را بگیر.

این پروژه برای ساخت بدون Android Studio تنظیم شده است.
